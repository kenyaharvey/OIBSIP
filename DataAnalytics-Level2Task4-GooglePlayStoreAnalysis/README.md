Google Play Store Analysis

A full data analysis pipeline on the Google Play Store apps and user reviews datasets — from raw, messy CSV/XLSX files to cleaned data, exploratory visualizations, and sentiment analysis.

What this covers:

Data cleaning: fixed shifted rows, encoding issues, inconsistent types, duplicates, and missing values
Category and ratings analysis across 33 app categories
App size vs. installs correlation
Pricing analysis, including detection of "novelty" outlier apps
Sentiment analysis on 35K+ user reviews using VADER
Sentiment breakdown by category
Interactive Plotly visualization
Data-driven conclusions for developers planning a new app launch

Tech stack: Python, pandas, matplotlib, VADER, Plotly, Jupyter Notebook# google-play-store-analysis.
