# Retail Sales Exploratory Data Analysis

## Project Overview

This project performs an exploratory data analysis (EDA) on a retail sales dataset to uncover sales trends, customer behavior patterns, and actionable business insights.

The goal was to analyze transaction data, understand customer demographics, identify revenue drivers, and provide recommendations to support business decision-making.

## Dataset

The dataset contains 1,000 retail transactions with the following columns:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Analysis Performed

### Data Inspection

- Checked dataset shape
- Reviewed data types
- Checked for missing values

### Descriptive Statistics

Calculated:

- Mean
- Median
- Mode
- Standard deviation

for numerical variables.

### Time Series Analysis

Analyzed sales trends using:

- Monthly sales trends
- Quarterly sales trends

### Customer Demographics Analysis

Analyzed:

- Customer age groups
- Gender distribution

### Product Analysis

Analyzed:

- Best-selling product categories
- Revenue by product category

### Correlation Analysis

Created a correlation heatmap to identify relationships between numerical variables.

### Additional Analysis

Analyzed average spending patterns across different age groups.

## Business Recommendations

1. Optimize inventory planning based on high-demand product categories.

2. Create targeted marketing campaigns based on customer demographics.

3. Use seasonal sales trends to improve promotional planning and inventory decisions.

4. Focus on high-revenue product categories to maximize growth opportunities.
